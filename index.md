Implements the generalized binomial framework for transforming
statistical moments of any order across arbitrary origins. Provides a
unified method for raw-to-raw, raw-to-central, and central-to-raw moment
conversions using a single origin-shift parameter b = a - k and the
symbolic binomial operator (a + b)^r with a^j -\> mu'\_j(a). Includes
functions for moment transformation, direct moment computation from
data, and validation against theoretical distributions (Binomial,
Normal).
